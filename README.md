# Code Repository: Emergence of Cooperation in Trust-Driven Coevolutionary Networks

This repository provides supplementary information for the research paper: "Emergence of cooperation in trust-driven coevolutionary networks" (2026).

## Code & Data Availability

To ensure academic integrity and properly manage the distribution of the core simulation engine, the complete source code (MATLAB scripts) and pre-computed datasets are hosted in a private repository. 

**Code and datasets are available upon reasonable request.**
